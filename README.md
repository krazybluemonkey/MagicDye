# Magic Dye
A fully customizable dye mod for Terraria, made for tmodloader v2026.6.3.4+

This repo also houses it's sibling mod, Magic Dye: Supplementaries.

Spiritual successor to [Dye Hard](https://github.com/krazybluemonkey/DyeHard).

For a full run down of everything the mod has to offer, reffer to it's forum topic.

No AI was used in the making of these mods. These mods were made by myself, with help from others on the tModLoader discord or visual studio 2022's error syntax handler. So if anything is off, that's on me.
